# Avatar artwork attribution

The fruit avatar SVGs in this folder are from **Twemoji**.

- Source: https://github.com/jdecked/twemoji (maintained fork of twitter/twemoji)
- Version: 15.1.0
- Graphics license: **CC-BY 4.0** — https://creativecommons.org/licenses/by/4.0/
- Copyright 2019 Twitter, Inc and other contributors.

These are open-licensed emoji graphics, **not** any vendor's proprietary account
avatars. Per CC-BY 4.0 we credit the source here; keep this note with the assets.

Each file is named by a readable fruit slug (e.g. `banana.svg`). The slug list is the
allocation pool in `src/core/people.ts`; the slug → asset mapping lives in
`src/assets/avatars/index.ts`. Avatars render as a glyph centered on the person's
accent-color circle.
